A program that sends exactly one deadpan one-star review — breathing, the unpaid labour done non-stop since birth, with no pay, no breaks, and nobody in management to complain to — for make.fun's "One-Star Review of Something Essential" bounty. A house judge compares entries two at a time on the brief: is it a one-star review of an everyday essential, does it find the sharpest true grievance, does it hold the deadpan, does it turn in the last few words, and is it tight and specific.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```
